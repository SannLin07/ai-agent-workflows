# Troubleshooting knowledge base

This directory starts empty because no real project incidents have been verified for this library. Add one Markdown record per reusable, observed issue using [`templates/troubleshooting/troubleshooting-record.md`](../templates/troubleshooting/troubleshooting-record.md).

Organize records by broad technical area only when entries exist (for example `flutter/`, `android/`, `ios/`, `dependencies/`, `firebase/`, or `networking/`). Use searchable filenames. Record exact environment and evidence, distinguish hypotheses from confirmed root cause, and include how the fix was verified. Never include secrets or private user data.
